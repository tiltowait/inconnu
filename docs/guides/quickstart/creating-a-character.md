# Creating a character

You can have as many characters as you like, on as many servers as you like. Each one belongs to the server you made it on. Type:

```
/character wizard
```

This gives you a link to a web-based character wizard, where you enter your character's name, trackers, Traits, specialties, and Convictions.

> [!NOTE]
> You don't _need_ a character to use **Inconnu**, but the rest of this Quickstart won't work without one!
