# /tags

This command shows you your post tags in alphabetical order, with a number indicating the total times you've used that tag. By selecting a tag from the menu, you may view all posts with that tag. Clicking the character name at the top of the embed will jump you to that post.

If you select multiple tags, only those posts that feature each selected tag will be shown.

![You can select multiple tags at once.](../../assets/tags_demo.png "You can select multiple tags at once.")

> [!TIP]
> Only you may see your tags. Feel free to call them whatever you like.

> [!WARNING]
> **If a post was deleted,** then it will not show in the tag count, nor will it show in the tag viewer.
