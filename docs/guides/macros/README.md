# 🧲 Macros

Macros allow you to automate aspects of your rolls. With a single command, you can roll a complex pool, make a Rouse check, earn Stains for Oblivion rolls, and even slake Hunger. Click over to the next page to start learning.

> [!TIP]
> You may add as many macros to a character as you need.
