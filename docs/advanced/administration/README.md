# Administration

Server administrators can use the `player` option to work with other players' characters in these commands:

* `/vr` and `/roll`
* `/character display`, `/character update`, and `/character adjust`
* `/character profile`, `/character convictions`, and `/character images`
* `/traits list`
* `/stain`
* `/statistics`
* `/experience log`
* `/experience award`, `/experience deduct`, and `/experience remove entry`, where `player` is required

In addition, admins can:

* [Award and deduct experience](experience-management.md)
* [Transfer characters](character-transfers.md) between players
* Change [server settings](../server-settings.md#server-settings)
* Leave rolls out of [statistics](../../command-reference/miscellaneous.md#statistics)
