# Willpower re-rolls

You can spend a point of Willpower to re-roll up to three normal dice, as long as the roll includes an Attribute or Skill.

Every roll comes with four re-roll buttons:

* **Re-Roll Failures:** Re-roll up to three failing dice. You'll use this the most.
* **Max Crits:** Re-roll up to three failing dice. If there are fewer than three failures, **Inconnu** makes up the difference with successes that aren't tens.
* **Avoid Messy:** Re-roll tens to try to avoid a messy critical. It's only available when that's possible: exactly one Hunger ten, and no more than three normal tens.
* **Risky Avoid:** Like `Avoid Messy`, but with fewer than three tens it re-rolls failures, too, so it needs at least one failure. Use it if losing the crit would make you fail the roll; otherwise, `Avoid Messy` is usually the better choice.

> [!WARNING]
> **Be careful!** `Re-Roll Failures` and `Max Crits` can turn rolls messy. Check for Hunger tens before you spend Willpower.

If your pool names Traits but none of them is an Attribute or Skill, the buttons are replaced by **WP Unavailable**.

After a re-roll with a character, a **Mark WP Use** button marks off the Willpower you spent, so you don't need `/character adjust`. If the server has a [character updates channel](../../advanced/server-settings.md#character-updates-channel), it's noted there, too.
