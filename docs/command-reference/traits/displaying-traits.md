# Displaying Traits

This command shows you a list of the character's traits, grouped by category (attributes/skills and physical/mental/social).

```
/traits list
```

The following optional parameters are available:

| Parameter   | Description                                       | Notes               |
| ----------- | ------------------------------------------------- | ------------------- |
| `character` | The name of the character whose traits to display |                     |
| `player`    | The player who owns the charactor                 | Administrators only |
