# Profiles

## Convictions

### Setting

```
/character convictions edit:<character>
```

This command will surface a modal dialogue with three text fields for you to enter your Convictions.

### Displaying

```
/character convictions
```

This command simply displays your character's Convictions.

> [!NOTE]
> Admins can view the convictions of other players' characters via the optional `player` and `character` parameters. Alternatively, you may right-click a username, hover over "Apps", and click "Convictions".

## Profile

All characters have a public profile viewable by anyone. This profile contains biography and description. [Premium users](../../premium/supporter-only-features.md) can upload images via `/character image upload`.

### Setting

```
/character profile edit:<character>
```

### Displaying

```
/character profile player:[player] character:[character]
```

> [!NOTE]
> If you set a profile, certain bot responses will include link to view your profile in a web browser.
