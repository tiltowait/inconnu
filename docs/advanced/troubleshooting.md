# Troubleshooting

**Inconnu** requires the following permissions:

* **Send Messages:** Should be obvious, no?
* **Use External Emoji:** For displaying individual dice throws and tracker boxes
* **Manage Webhooks:** For [Roleposting](../premium/roleposting.md)

Members also need the _Use Application Commands_ permission, since all of **Inconnu's** commands are slash commands.

### Inconnu isn't showing emoji

If **Inconnu** isn't showing its emoji, check that it has the _Use External Emoji_ permission for that channel. Additionally, the `@everyone` role requires this permission as well. This is a hard Discord requirement for the slash commands feature required since September 2022.

If the permissions are correct, check that emojis are turned on in both [your settings](server-settings.md#use-emojis) and [the server's](server-settings.md#use-emojis-server).

### Inconnu's replies are blank

Check your Discord settings. _Show website preview info from links pasted into chat_ under _Text & Images_ needs to be **enabled**. If replies are _still_ blank, you may be using antivirus software that blocks the embeds. In particular, certain versions of McAfee have been known to do this.

### You aren't able to upload images

Make sure you've done the following:

* [Become a patron of any tier](https://www.patreon.com/tiltowait) (**Note:** If you pledged before the tiers existed, you will need to update your pledge)
* [Connect Patreon to Discord](https://support.patreon.com/hc/en-us/articles/115002341603)
* [Join the official server](https://discord.gg/QHnCdSPeEE)

If you are still unable to upload images, please ask for help in `#inconnu-support`.

> [!NOTE]
> If you restart a canceled membership or change your credit card, Patreon sometimes won't update your supporter status. If this happens, please leave the server and join again.

> [!WARNING]
> **If you are an older patron but not subscribed to a tier**, you must change your pledge to any of the new tiers.
