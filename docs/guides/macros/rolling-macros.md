# Rolling macros

Now that we've [created a macro](your-first-macro.md), rolling it is simple!

> [!NOTE]
> **Rolling a Macro**
>
> ```
> /vm syntax:<macro name> [optional modifiers]
> ```

The `macro name` should be obvious. It's the name of your macro.

> [!TIP]
> **Example:** Rolling Nadea's _hunt_ macro.
>
> ```
> /vm syntax:hunt
> ```
