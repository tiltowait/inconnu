# Inconnu

**Inconnu** is a Discord dice roller and character manager for _Vampire: The Masquerade_ 5th Edition. Roll by naming your Traits, keep your character's trackers in one place, and let **Inconnu** handle the bookkeeping.

New here? Start with the [Quickstart](guides/quickstart/README.md). To add **Inconnu** to your server, [invite it](https://discord.com/api/oauth2/authorize?client_id=882409882119196704&permissions=536872960&scope=bot%20applications.commands).

Playing V20 or _Chronicles of Darkness_? Try [Botch (V20) or Beat (CofD)](https://docs.botch.lol).

## Dice rolling

[Roll](command-reference/rolls/README.md) a pool with Hunger and a Difficulty, using numbers, [Traits](guides/quickstart/rolling-with-traits.md), or both. Rolls support [Willpower re-rolls](guides/quickstart/willpower-re-rolls.md) and Blood Surges, **Inconnu** applies [Impairment](command-reference/rolls/impairment.md) for you, and you can [hide your dice](command-reference/rolls/hidden-dice.md) from other players.

## Characters

Create a character in the web-based [character wizard](guides/quickstart/creating-a-character.md), then [track](command-reference/characters.md) Health, Willpower, Humanity, Hunger, and experience as you play. Every character has a public profile, with a biography, description, and Convictions.

## Traits

Attributes, Skills, Disciplines, specialties, powers, and any [custom Traits](guides/quickstart/custom-traits.md) you add can all be [rolled by name](command-reference/traits.md), and you only need to type enough of a name to identify it.

## Macros

[Save a roll](guides/macros.md) you make often, along with its Rouse Checks, Stains, and Hunger slaking, and roll it with one short command.

## Shortcuts

[Gameplay shortcuts](guides/gameplay-shortcuts.md) handle Rouse Checks, awakening, mending, slaking, Remorse, frenzy, and more, updating your character as they go.

## Premium

[Supporters](https://www.patreon.com/tiltowait) can add [character images](premium/character-images.md) and post as their characters with [Roleposting](premium/roleposting.md).

## For Storytellers

[Admins](advanced/administration/README.md) can [change server settings](advanced/server-settings.md#server-settings), see character updates in one channel, [manage experience](advanced/administration/experience-management.md), and work with any player's character.
