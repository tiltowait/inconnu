# Just the basics

Don't care about managing characters? Trait pools don't interest you? That's fine; you can still use **Inconnu** via the basic roll syntax below.

> [!NOTE]
> **Basic Roll Syntax**
>
> ```
> /roll pool:<POOL> hunger:<HUNGER> difficulty:<DIFFICULTY>
> ```

But if you stop here, you're missing out on the dozens of features **Inconnu** offers. Read on for more info.
