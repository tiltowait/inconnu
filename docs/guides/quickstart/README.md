# Quickstart

This guide takes you from a basic roll to a fully tracked character: creating one, rolling with its Traits, re-rolling with Willpower, and keeping its trackers current. Each page builds on the last, so follow the **Next** links at the bottom of each page.

> [!NOTE]
> Throughout this guide, `<angle brackets>` mark **required** parameters and `[square brackets]` mark **optional** ones. Where an optional parameter has a default, we'll say so.

> [!WARNING]
> **Discord shows each parameter's name before your input.** When you see `/vr syntax:7 3 2`, you **don't** type `syntax:`; Discord adds it for you.
