# 💰 Supporter-only features

**Inconnu's** core features are and always will be free. Certain features, however, require [becoming a patron](https://www.patreon.com/tiltowait) to use.

At present, the only such feature is character image support. **Inconnu** used to have rudimentary support for displaying character images, but this is being phased out for a more streamlined and more powerful system that removes the need for you to host the images yourself.

> [!NOTE]
> **Users who already had an image set may keep that image without becoming a patron.** Note, however, that you will no longer be able to edit that image, only delete it, and you will not be able to upload additional images without becoming a patron. Thanks for your support!
