# Quickstart

This guide takes you from a basic roll to a fully tracked character: creating one, rolling with its Traits, re-rolling with Willpower, and keeping its trackers current. Each page builds on the last, so follow the **Next** links at the bottom of each page.

> [!NOTE]
> Throughout this guide, you will see parameters enclosed in `<angle brackets>` and `[square brackets]`. This is important! `<angle brackets>` means that a parameter is **required**, while `[square brackets]` indicate it is **optional**. For optional parameters, a **default** value will be indicated when applicable.

> [!WARNING]
> **Discord likes to put the names of the parameters before your input.** When you see a command like `/vr syntax:7 3 2`, _**you do not**_ type the `syntax:` portion! Discord adds it for you automatically.
