# Administration

Storytellers are server admins and members with the server's [Storyteller role](../server-settings.md#storyteller-role). They can use the `player` option to work with other players' characters in these commands:

* `/vr` and `/roll`
* `/character display`, `/character update`, and `/character adjust`
* `/character convictions`
* `/traits list`
* `/stain`
* `/statistics`
* `/experience log`
* `/experience award`, `/experience deduct`, and `/experience remove entry`, where `player` is required

In addition, Storytellers can:

* [Award and deduct experience](experience-management.md)
* [Transfer characters](character-transfers.md) between players
* Make and use [SPCs](../../command-reference/characters.md#character-wizard)
* Leave rolls out of [statistics](../../command-reference/miscellaneous.md#statistics)

Only admins can change [server settings](../server-settings.md#server-settings).
