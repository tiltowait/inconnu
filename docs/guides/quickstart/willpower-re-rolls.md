# Willpower re-rolls

V5's rules as written ("RAW") allow you to re-roll up to three normal dice by spending a point of Willpower, so long as the roll incorporates an Attribute or a Skill—and so does **Inconnu**!

Every time you roll, four buttons will display at the bottom of the roll view:

* **Re-Roll Failures:** Re-roll up to three dice that failed. This is far and away the most commonly pressed button.
* **Max Crits:** Re-roll up to three failing dice. If fewer than three dice are failures, **Inconnu** will re-roll normal successes (but not tens) in order to make up the difference.
* **Avoid Messy:** Re-roll tens in order to attempt to avoid a messy critical. This button is only available when a re-roll can avoid the messy critical: exactly one Hunger ten, and no more than three normal tens.
* **Risky Avoid:** Just like `Avoid Messy`, this button also re-rolls tens. If there are fewer than three tens, however, it will begin re-rolling failure dice, so it needs at least one failure. Use this button if losing the crit would see you fail the roll. Otherwise, `Avoid Messy` is the better option nine times out of ten.

> [!WARNING]
> **Be careful!** `Re-Roll Failures` and `Max Crits` can lead the unwary into messy critical territory. Always check whether any of the Hunger dice are tens before deciding whether to use Willpower.

If your pool names Traits but none of them is an Attribute or Skill, the buttons are replaced by **WP Unavailable**.

Once you've re-rolled, if you're rolling with a character, a **Mark WP Use** button marks off the spent point of Willpower, so you don't have to use `/character adjust`. If the server has a [character updates channel](../../advanced/server-settings.md#character-updates-channel), **Inconnu** notes it there, too.
