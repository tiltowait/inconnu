# 🎭 Creating a character

You may store as many characters on as many servers as you like. Each character is unique to the server on which you created it. Simply type:

```
/character wizard
```

This gives you a link to a web-based character wizard, where you enter your character's name, trackers, traits, specialties, and Convictions.

> [!NOTE]
> You don't _need_ a character to use **Inconnu**, but the rest of this quickstart guide won't work without one!
