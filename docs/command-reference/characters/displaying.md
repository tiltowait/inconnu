# Displaying

```
/character display character:[character]
```

This command displays your character's basic details, including Health, Willpower, Humanity, and experience. To view traits, including Attributes and Skills, you may click the "Traits" button at the bottom of the embed.

| Parameter   | Description                          | Notes               |
| ----------- | ------------------------------------ | ------------------- |
| `character` | The name of the character to display | Optional            |
| `player`    | The player who owns the charactor    | Administrators only |

> [!NOTE]
> If you have multiple characters, you will be shown a list to choose from.
